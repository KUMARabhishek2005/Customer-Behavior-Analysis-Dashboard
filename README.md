# Customer Behavior Analysis Dashboard

An end-to-end retail analytics project that transforms customer transaction data into actionable business insights using Python, PostgreSQL, SQL, and Power BI.

## Project Overview

Retail businesses generate large amounts of transactional data, but extracting meaningful insights can be challenging. This project analyzes shopping behavior data from 3,900 customers to identify purchasing patterns, revenue drivers, and customer preferences.

* Built a complete analytics pipeline from raw data to dashboard
* Analyzed customer purchasing behavior and revenue trends
* Delivered insights through an interactive Power BI dashboard

## Business Objectives

The analysis was designed to answer key business questions and support data-driven decision-making.

* Identify high-value customer segments
* Evaluate the effectiveness of discounts
* Discover top-performing products, categories, and locations

## Dataset

The dataset contains customer demographics, transaction details, product information, and shopping behavior metrics.

* 3,900 customer records
* 16 business-related features
* Retail and e-commerce domain data

## Data Preparation

The raw dataset was cleaned and transformed using Python before being loaded into PostgreSQL for analysis.

* Standardized column names and data types
* Performed data quality checks
* Created age-group segments for customer analysis

## SQL Analysis

Business questions were answered using SQL queries focused on customer behavior and revenue performance.

* Developed 13 analytical SQL queries
* Used aggregations, subqueries, and CASE statements
* Applied ranking and window functions for advanced analysis

## Power BI Dashboard

An interactive dashboard was created to visualize business performance and customer trends.

* KPI cards for revenue, customers, ratings, and order value
* Revenue analysis by season, category, and discount status
* Customer, product, and location insights

## Key Insights

The analysis uncovered several patterns that can help improve business strategy and customer targeting.

* Non-discounted purchases generated higher revenue
* Fall was the highest-performing sales season
* Clothing was the largest revenue-generating category

## Results

The project successfully transformed raw transactional data into actionable business insights.

* Total Revenue: $233,081
* Total Customers: 3,900
* Average Order Value: $59.76

## Tech Stack

The project was developed using industry-standard analytics tools and technologies.

* Python (Pandas, SQLAlchemy)
* PostgreSQL & SQL
* Power BI & DAX
